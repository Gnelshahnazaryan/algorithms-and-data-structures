# Linear Search

## Overview

Linear Search is the simplest searching algorithm.  
It works by checking each element of an array sequentially until the target value is found or the array ends.

Unlike **Binary Search**, Linear Search **does not require the array to be sorted**.

---

## How It Works

1. Start from the first element of the array.
2. Compare each element with the target value.
3. If the element matches the target → return its index.
4. If the end of the array is reached without finding the element → return `-1`.
